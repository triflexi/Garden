# Проверка реализации

Проверено 23 октября 2026. Приложение собрано и запущено целиком в Docker по HTTP.

## Установка и сборка

- Официальный `shadcn init @coss/style` успешно завершён; установлен Base UI и исходники Coss.
- Официальный `shadcn add @aceternity/liquid-glass` успешно завершён; компонент используется в интерфейсе.
- Чистая установка `npm ci`, TypeScript и production-сборки API и фронтенда проходят.
- `npm audit`: 0 уязвимостей. Vitest обновлён до 5; исправленные deepmerge-ts и js-yaml закреплены через overrides.
- Оба production Docker-образа собираются. Миграции выполняются отдельным контейнером перед API.

## Проверки поведения

- 20 тестов API прошли, включая 10 интеграционных с настоящей PostgreSQL: аккаунты, cookie-сессии, изоляция данных, CRUD, идемпотентный полив, отмена, статистика, истечение сессии и сохранение просмотров.
- 7 тестов фронтенда прошли: русские даты, UUID для HTTP, темы, учёт навигации без повторных рендеров, обновление сессии и очистка приватного кеша при выходе.
- 2 Playwright-сценария проходят через production Nginx/API/PostgreSQL: регистрация, повторный вход, добавление и редактирование растения, полив и отмена, перезагрузка, статистика, мобильная вёрстка и обе темы.
- При визуальной проверке исправлен долгий переход фона Coss Input, мешавший смене темы. В E2E добавлена проверка изменения фона поля.
- Снимки desktop/mobile и обеих тем сохраняются в `test-results/`; папка исключена из Git.
- 4 Linux-сценария скрипта деплоя проходят: успех, ошибка миграции, ошибка запуска и неуспешный health check. Проверены backup до обновления и возврат предыдущих образов.

## Docker и мониторинг

- Запущены PostgreSQL, API, Nginx, VictoriaMetrics, Grafana, node-exporter, cAdvisor и blackbox-exporter.
- `scripts/smoke.sh` проходит: доступны цели и реальные метрики CPU/RAM/диска/контейнерных лимитов; Grafana получает дашборд; backup восстанавливается во временную БД с проверкой количества записей.
- При остановке PostgreSQL readiness возвращает 503, liveness остаётся 200, `/metrics` продолжает работать с `app_database_up 0`. Диагностические запросы ограничены по времени.
- При остановке API blackbox фиксирует отказ. После возврата БД и API приложение снова доступно.
- cAdvisor 0.60.6 совместим с Docker 29/containerd; сохраняются только необходимые Compose-метки.
- Дисковые панели поддерживают корневой раздел Linux VPS и диск Docker Desktop. На Windows мониторинг описывает Linux VM Docker.
- Grafana опубликована только на 127.0.0.1:3001; приложение — localhost:8080. Для VPS в `.env` задаются HTTP_PORT=80 и PUBLIC_ORIGIN=http://IP. TLS и сертификаты не настраиваются.

## Конфигурации

GitHub Actions проходят actionlint; Linux-скрипты — bash -n; Compose-конфигурации и Nginx — проверку синтаксиса. Исходники отформатированы Prettier. Секреты находятся только в исключённом из Git `.env`.

CI/CD-файлы готовы. Реальный запуск GitHub Actions и SSH-деплой на VPS не выполнялись: репозиторий, сервер и секреты не предоставлены. Настройка описана в README.
