# Интерфейс «Листва»

React, Vite, TypeScript, Tailwind CSS, Coss / Base UI и Aceternity Liquid Glass. Русский интерфейс, светлая, тёмная и системная темы.

Команды запуска, Docker, тесты и CI/CD описаны в [корневом README](../../README.md). Источники UI-компонентов указаны в [SOURCES.md](src/components/ui/SOURCES.md).
