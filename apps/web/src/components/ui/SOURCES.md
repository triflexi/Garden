# Источники компонентов

`button.tsx`, `input.tsx`, `spinner.tsx` и `lib/utils.ts` получены из официального реестра Coss UI в репозитории https://github.com/cosscom/coss/tree/main/apps/ui/public/r. Пути импортов адаптированы к этому проекту; подпись спиннера переведена на русский.

Пресет Coss установлен официальной командой `shadcn init @coss/style`; Liquid Glass — `shadcn add @aceternity/liquid-glass` из реестра Aceternity. Обе команды успешно завершены 23 октября 2026. Настройки реестров сохранены в components.json. Компоненты распространяются как исходный код, устанавливаемый shadcn CLI.
